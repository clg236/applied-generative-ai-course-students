# After class

## Your one lunch task

**Create a free account at [openrouter.ai](https://openrouter.ai/).**

You are done when you have:

1. signed up;
2. opened the **Chat** page; and
3. added one model to the pane (the **Add Model** button).

Step 3 takes ten seconds and it is the only step that proves the account actually works. "I made an account" is not the same thing.

## Read this before you start

- **Free requires a signup.** If you try to send a prompt without an account, the site asks you to sign up. Free means no payment; it does not mean no account.
- **No install, no key, nothing to download.** Credit is optional: about $5 is recommended because the free tier truncates, but the $0 route works and is not penalised.
- **Do not go looking for an API key.** Week 1 is the web interface only. Keys, terminals, and agents start in Session 4.
- If you want to look around while you are there, open the model picker and find the models labelled **(free)**. Which ones are free changes from week to week, so learn the label rather than a name.

## If it will not work

Come find Christian before 2:00 PM — it is usually a two-minute fix. The two things that actually go wrong are an email verification that never arrives (check spam, then try a different address) and a managed or locked-down browser (try a personal browser or a private window).

Still blocked at 2:00? That is fine. Pair with a neighbour's screen for the afternoon and we will sort the account out afterwards. You will not miss anything and there is no penalty.

**Never paste a password, one-time code, or verification link into a help message or a chat window.**

## Ready for 2:00 PM

Return with:

- a charged laptop;
- a browser; and
- a working OpenRouter account with the Chat page open — or a clear description of where the signup stopped.
